# Architecture: Sample-Domain Trigger Engine

## 1. Subsystem Overview

Система синхронизации (Trigger Engine) осциллографа отвечает за стабилизацию периодических сигналов на экране и захват переходных/апериодических процессов в реальном масштабе времени.

В соответствии с фундаментальными принципами архитектуры (`GEMINI.md` Rule 1, 2, 3), триггер функционирует исключительно в **дискретной области выборок (Acquisition / Sample Domain)** на частотах дискретизации 1–5 MSPS непосредственно перед или внутри кольцевого буфера выборок, а не на децимированном буфере дисплея.

## 2. Математическая модель детектора (TriggerDetector)

### 2.1 Компаратор с гистерезисом (Триггер Шмитта)
В реальных аналоговых трактах осциллографов высокочастотные шумы и дрожание амплитуды приводят к ложным многократным срабатываниям на фронтах с малой крутизной. Для подавления этого эффекта используется бинарная схема гистерезиса с зоной нечувствительности $[V_{\text{level}} - V_{\text{hyst}}, V_{\text{level}} + V_{\text{hyst}}]$.

Состояние компаратора `_isArmed`:
- **Нарастающий фронт (`RISING`)**:
  - Компаратор **взводится**, когда входной сигнал строго меньше нижнего порога:
    $$x[k] < V_{\text{level}} - V_{\text{hyst}}$$
  - Событие триггера фиксируется в момент, когда взведенный компаратор фиксирует превышение верхнего порога:
    $$x[k] \ge V_{\text{level}} + V_{\text{hyst}}$$
  - При обнаружении события флаг `_isArmed` сбрасывается в `false`, блокируя повторные срабатывания до следующего пересечения нижнего порога.

- **Спадающий фронт (`FALLING`)**:
  - Компаратор **взводится**, когда сигнал строго выше верхнего порога:
    $$x[k] > V_{\text{level}} + V_{\text{hyst}}$$
  - Событие триггера фиксируется при переходе ниже нижнего порога:
    $$x[k] \le V_{\text{level}} - V_{\text{hyst}}$$

### 2.2 Время удержания (Trigger Holdoff)
После каждого подтвержденного события триггера активируется счетчик удержания:
$$N_{\text{holdoff}} = \text{round}(T_{\text{holdoff}} \cdot f_s)$$
В течение следующих $N_{\text{holdoff}}$ отсчетов любые события триггера игнорируются, а компаратор удерживается в невзведенном состоянии. Это обеспечивает синхронизацию по первому импульсу в пачках сложных сигналов (bursts, PWM, frame sync).

### 2.3 Субдискретная интерполяция (Sub-sample Interpolation)
Истинный момент времени пересечения порогового уровня $V_{\text{level}}$ обычно лежит между дискретными отсчетами $x[k-1]$ и $x[k]$.
Линейная интерполяция вычисляет дробную задержку $\delta \in [0.0, 1.0)$:
$$\delta = \frac{V_{\text{level}} - x[k-1]}{x[k] - x[k-1]}$$
Точное непрерывное время события относительно начала выборки:
$$t_{\text{trig}} = \frac{k - 1 + \delta}{f_s}$$

## 3. Машина состояний и окно захвата (TriggerEngine)

### 3.1 Разбиение окна наблюдения (Pre-Trigger / Post-Trigger)
Полная ширина экрана осциллографа составляет 10 делений по горизонтали:
$$T_{\text{screen}} = 10 \cdot \text{timeDiv}$$
Общее число отсчетов в кадре наблюдения:
$$N_{\text{window}} = \text{round}(T_{\text{screen}} \cdot f_s)$$

Положение метки триггера по горизонтали задается параметром $P_{\text{trig}} \in [0.0, 1.0]$ (где 0.5 — центр экрана, 5 делений):
- **Пре-триггер** (история сигнала до события):
  $$N_{\text{pre}} = \text{round}(N_{\text{window}} \cdot P_{\text{trig}})$$
- **Пост-триггер** (сигнал после события):
  $$N_{\text{post}} = N_{\text{window}} - N_{\text{pre}}$$

### 3.2 Семантика режимов развертки (Sweep Modes)

```
        ┌─────────────────────────────────────────────────────────┐
        │                       UNTRIGGERED                       │
        └────────────────────────────┬────────────────────────────┘
                                     │ Start / Reset
                                     ▼
        ┌─────────────────────────────────────────────────────────┐
        │                       PRE_TRIGGER                       │
        │     (Накопление N_pre отсчетов пре-триггера)            │
        └────────────────────────────┬────────────────────────────┘
                                     │ N_pre накоплено
                                     ▼
        ┌─────────────────────────────────────────────────────────┐
        │                         ARMED                           │
        │             (Поиск события триггера)                    │
        └──────────────┬───────────────────────────┬──────────────┘
                       │ Trigger Found             │ Timeout (AUTO only)
                       ▼                           ▼
        ┌────────────────────────────┐   ┌────────────────────────┐
        │        TRIGGERED           │   │      FORCED_AUTO       │
        └──────────────┬─────────────┘   └─────────────┬──────────┘
                       │ Ждем поступления N_post       │
                       ▼                               │
        ┌──────────────────────────────────────────────┴──────────┐
        │                         READY                           │
        │              (Кадр готов к отображению)                 │
        └──────────────┬───────────────────────────┬──────────────┘
                       │ Режим AUTO / NORMAL       │ Режим SINGLE
                       ▼                           ▼
              Сброс в PRE_TRIGGER              STOPPED
```

1. **AUTO (Автоматический)**:
   - При наличии синхронизации работает синхронно с сигналом (`isLocked = true`).
   - При отсутствии фронтов по истечении `autoTimeout` (100 мс) принудительно формирует псевдо-синхронный кадр с текущего конца буфера. Позволяет оператору наблюдать постоянные напряжения (DC) и сигналы с амплитудой ниже порога.
2. **NORMAL (Ждущий)**:
   - Кадр формируется только при наличии истинного события триггера.
   - Если сигнал отсутствует или порог выставлен выше пика сигнала, развертка не запускается, а экран сохраняет последний захваченный кадр.
3. **SINGLE (Однократный)**:
   - Захватывает ровно один полный кадр (`N_pre` + событие + `N_post`).
   - Сразу после готовности кадра отправляет команду остановки в домен осциллографа (`STOP`) и переходит в состояние `STOPPED`.

## 4. Алгоритм устранения фазового дрожания (Zero-Jitter Display Alignment)

Для предотвращения дрожания отображаемой кривой на экране осциллографа (`extractDisplayBuffer`):
1. Индекс точки триггера на экране жестко привязан к $I_{\text{target}} = \text{round}(P_{\text{trig}} \cdot N_{\text{points}})$.
2. Шаг прореживания (децимации):
   $$S = \frac{N_{\text{window}}}{N_{\text{points}}}$$
3. Непрерывный индекс считывания отсчета в кольцевом буфере для точки дисплея $i \in [0, N_{\text{points}}-1]$:
   $$\text{idx}_{\text{float}} = k_{\text{trig}} + (i - I_{\text{target}}) \cdot S + \delta$$
4. Округление $\text{round}(\text{idx}_{\text{float}})$ гарантирует, что точка фронта сигнала всегда попадает ровно в координату $I_{\text{target}}$ на экране с погрешностью менее $\pm 0.5$ отсчета, полностью исключая бег фазы при стационарных сигналах.
