# DSP Reference Algorithms & Mathematical Oracle Specification

## 1. Назначение и контекст

В рамках архитектуры цифрового двойника осциллографа подсистема DSP выполняет функции измерения параметров сигналов (автоматические измерения в реальном времени), триггерной синхронизации и частотной фильтрации.

В соответствии с правилом `GEMINI.md` (п. 18 «No premature optimization») библиотека `src/dsp/` реализована на языке TypeScript/JavaScript в виде **математического оракула** (Ground-Truth Oracle). Она служит эталоном точности и верификации для низкоуровневых WebAssembly-ядер и аппаратных симуляторов.

## 2. Математические формулы и алгоритмы

### 2.1 Статистические параметры

#### 2.1.1 Математическое ожидание / Среднее (Mean / DC Offset)
$$\mu = \frac{1}{N} \sum_{i=0}^{N-1} x[i]$$
- **Численное допущение**: Накопление суммы ведется в `Float64` для исключения катастрофической потери значимости при больших $N$ ($N \ge 10^6$).
- **Погрешность**: $|e_{\mu}| < 10^{-6}$ для симметричных сигналов.

#### 2.1.2 Экстремумы (Min, Max)
$$\min = \min_{0 \le i < N} x[i], \quad \max = \max_{0 \le i < N} x[i]$$
- **Погрешность**: Точное равенство (0 error) для IEEE 754 float32/float64.

#### 2.1.3 Размах сигнала (Peak-to-Peak, $V_{pp}$)
$$V_{pp} = \max - \min, \quad V_{pp} \ge 0$$

#### 2.1.4 Среднеквадратичное значение (True RMS, $V_{rms}$)
$$V_{rms} = \sqrt{\frac{1}{N} \sum_{i=0}^{N-1} x[i]^2}$$
- **Эталонные значения (Golden Vectors)**:
  - Гармонический сигнал $A \sin(\omega t)$: $V_{rms} = \frac{A}{\sqrt{2}} \approx 0.70710678 \cdot A$
  - Прямоугольный меандр $\pm A$: $V_{rms} = A$
  - Треугольный / пилообразный сигнал $\pm A$: $V_{rms} = \frac{A}{\sqrt{3}} \approx 0.57735027 \cdot A$
  - Постоянный уровень $V_{dc}$: $V_{rms} = |V_{dc}|$
  - Смешанный сигнал $V_{dc} + A \sin(\omega t)$: $V_{rms} = \sqrt{V_{dc}^2 + \frac{A^2}{2}}$
- **Погрешность**: $|e_{rms}| < 10^{-5}$ для дискретных сеток с $N \ge 1000$ отсчетов на период.

### 2.2 Детектор пересечения нуля (Zero Crossing Detection)

#### 2.2.1 Субдискретная линейная интерполяция
Для устранения погрешности дискретизации, возникающей из-за целочисленного шага отсчетов, момент пересечения уровня $V_{th}$ между отсчетами $i-1$ и $i$ аппроксимируется линейной интерполяцией:
$$t_{cross} = (i - 1) + \frac{V_{th} - x[i-1]}{x[i] - x[i-1]}$$
где $t_{cross} \in [i-1, i)$ — дробный индекс отсчета.

#### 2.2.2 Подавление шума с помощью петли гистерезиса (Schmitt Trigger)
Для предотвращения множественных ложных срабатываний из-за шума задается зона нечувствительности $H$:
- Верхний порог: $V_{high} = V_{th} + \frac{H}{2}$
- Нижний порог: $V_{low} = V_{th} - \frac{H}{2}$
Переход считается положительным (RISING) только если сигнал предварительно находился ниже $V_{low}$ и превысил $V_{high}$.

#### 2.2.3 Различение касания и истинного пересечения
Если отсчет $x[i-1]$ в точности равен порогу $V_{th}$, алгоритм проверяет знак предшествующего отсчета $x[i-2]$:
- Если $x[i-2] < V_{th}$ и $x[i] > V_{th}$ $\implies$ истинный RISING переход.
- Если $x[i-2] > V_{th}$ и $x[i] > V_{th}$ $\implies$ касание (local minimum), пересечение **не регистрируется**.

### 2.3 Оценка частоты, периода и скважности (Frequency & Period Estimation)

#### 2.3.1 Оценка периода и частоты по полным циклам
Пусть $t_0, t_1, \dots, t_{M-1}$ — дробные метки последовательных восходящих (RISING) пересечений порога. Число полных периодов: $K = M - 1$.
$$T_{avg} = \frac{t_{M-1} - t_0}{K \cdot f_s}$$
$$f = \frac{1}{T_{avg}} = \frac{K \cdot f_s}{t_{M-1} - t_0}$$
где $f_s$ — частота дискретизации.

#### 2.3.2 Метрика достоверности (Confidence Metric)
Для каждого периода $k$ вычисляется длительность $\Delta t_k = t_{k+1} - t_k$ и среднеквадратичное отклонение джиттера $\sigma_T$:
$$\text{Confidence} = \max\left(0, 1 - 2 \cdot \frac{\sigma_T}{\bar{T}}\right)$$
Для строго периодических сигналов $\text{Confidence} \ge 0.95$.

#### 2.3.3 Скважность (Duty Cycle)
Определяется соотношением времени положительного импульса $T_{high}$ (между восходящим и последующим нисходящим переходом) к полному периоду $T$:
$$D = \frac{T_{high}}{T}$$

### 2.4 Фильтр с конечной импульсной характеристикой (FIR Filter)

#### 2.4.1 Разностное уравнение
$$y[n] = \sum_{k=0}^{M-1} b[k] \cdot x[n - k]$$
где $b[k]$ — весовые коэффициенты (импульсная характеристика $h[k] = b[k]$), $M$ — количество отводов (taps).

#### 2.4.2 Скользящее среднее (Moving Average)
$$b[k] = \frac{1}{M}, \quad \forall k \in [0, M-1]$$
Коэффициент передачи на постоянном токе: $H(0) = \sum b[k] = 1.0$.

#### 2.4.3 Оконный метод синтеза ФНЧ (Windowed-Sinc Low-Pass)
Нормализованная частота среза: $f_n = \frac{f_c}{f_s}$. Центральный отсчет: $M_c = \frac{M - 1}{2}$.
$$h[k] = \begin{cases} 2\pi f_n, & k = M_c \\ \frac{\sin(2\pi f_n (k - M_c))}{k - M_c}, & k \neq M_c \end{cases}$$
Сглаживающее окно Ханна (Hann Window):
$$w[k] = 0.5 - 0.5 \cos\left(\frac{2\pi k}{M - 1}\right)$$
Итоговые нормированные коэффициенты:
$$b[k] = \frac{h[k] \cdot w[k]}{\sum_{j=0}^{M-1} h[j] \cdot w[j]}$$

### 2.5 Фильтр с бесконечной импульсной характеристикой (IIR Filter)

#### 2.5.1 Транспонированная прямая форма II (Direct Form II Transposed)
Вместо прямой формы I, подверженной накоплению динамических ошибок в рекурсивных связях, используется транспонированная форма II для секции 2-го порядка (Biquad):
$$\begin{aligned}
y[n] &= b_0 x[n] + d_1[n-1] \\
d_1[n] &= b_1 x[n] - a_1 y[n] + d_2[n-1] \\
d_2[n] &= b_2 x[n] - a_2 y[n]
\end{aligned}$$
где $d_1, d_2$ — переменные состояния (линия задержки).

#### 2.5.2 Синтез фильтра Баттерворта 2-го порядка через билинейное преобразование
Билинейное преобразование аналогового прототипа с предварительным искажением частоты (Frequency Pre-Warping):
$$K = \tan\left(\frac{\pi f_c}{f_s}\right)$$
Для фильтра Баттерворта ($Q = \frac{1}{\sqrt{2}} \approx 0.70710678$):
$$\text{norm} = 1 + \frac{K}{Q} + K^2 = 1 + \sqrt{2} K + K^2$$
Нормализованные коэффициенты:
$$\begin{aligned}
b_0 &= \frac{K^2}{\text{norm}}, \quad b_1 = \frac{2 K^2}{\text{norm}} = 2 b_0, \quad b_2 = \frac{K^2}{\text{norm}} = b_0 \\
a_0 &= 1.0 \\
a_1 &= \frac{2 (K^2 - 1)}{\text{norm}} \\
a_2 &= \frac{1 - \sqrt{2} K + K^2}{\text{norm}}
\end{aligned}$$

- **Коэффициент передачи на постоянном токе ($f = 0$)**:
  $$H(0) = \frac{b_0 + b_1 + b_2}{1 + a_1 + a_2} = 1.000000 \quad (0\text{ dB})$$
- **Ослабление на частоте среза ($f = f_c$)**:
  $$|H(f_c)| = \frac{1}{\sqrt{2}} \approx 0.70710678 \quad (-3.0103\text{ dB})$$
- **Крутизна спада в полосе задерживания**:
  $-40\text{ dB/декаду}$ ($-12\text{ dB/октаву}$).

#### 2.5.3 Критерий устойчивости Джури (Jury Stability Criterion)
Знаменатель передаточной функции: $A(z) = 1 + a_1 z^{-1} + a_2 z^{-2}$.
Полюса фильтра строго лежат внутри единичной окружности ($|p_{1,2}| < 1$) тогда и только тогда, когда выполнены 3 условия:
1. $|a_2| < 1$
2. $1 + a_1 + a_2 > 0$
3. $1 - a_1 + a_2 > 0$
Если любое из условий нарушено, класс `IirBiquadFilter` выбрасывает исключение `DspError(DspErrorCode.UNSTABLE_FILTER)`.

## 3. Таблица численных допусков (Numerical Tolerances)

| Параметр / Алгоритм | Аналитический эталон | Численный допуск | Условие проверки |
|---|---|---|---|
| **Mean (DC)** | $V_{dc}$ | $\Delta < 10^{-6}$ | $N = 1000$, постоянный сигнал |
| **Mean (Symmetric AC)** | $0.0\text{ В}$ | $\Delta < 10^{-5}$ | Синусоида/меандр, целое число периодов |
| **Min, Max** | $-A, +A$ | $\Delta = 0$ (точное равенство) | Экстремумы выборки Float32 |
| **Peak-to-Peak** | $2 A$ | $\Delta = 0$ | $V_{pp} = \max - \min$ |
| **RMS (Синус)** | $A / \sqrt{2}$ | $\Delta < 10^{-4}$ | $N \ge 1000$ отсчетов на период |
| **RMS (Меандр)** | $A$ | $\Delta < 10^{-6}$ | Строгий меандр $\pm A$ |
| **RMS (Треугольник)** | $A / \sqrt{3}$ | $\Delta < 10^{-3}$ | Дискретная сетка $N = 1000$ отсчетов |
| **Zero Crossing** | $t_{analytical}$ | $\Delta < 0.01$ отсчета | Линейная интерполяция синусоиды |
| **Frequency** | $f_{target}$ | $\frac{|\Delta f|}{f} < 0.05\%$ | $N_{cycles} \ge 5$, $f_s \ge 10 f$ |
| **Duty Cycle** | $D_{target}$ | $|\Delta D| < 0.02$ | Прямоугольные импульсы 25% и 75% |
| **FIR DC Gain** | $1.000000$ | $\Delta < 10^{-6}$ | $y[n] \to \sum b[k]$ при step input |
| **IIR DC Gain** | $1.000000$ | $\Delta < 10^{-4}$ | Установившееся значение step input |
| **IIR Cutoff Gain** | $0.707107$ ($-3.01\text{ dB}$) | $\Delta < 0.01$ | Синусоида на частоте $f = f_c$ |

## 4. Обработка граничных условий (Edge Cases)

| Граничный случай | Поведение алгоритма | Код ошибки / Результат |
|---|---|---|
| Пустой буфер ($N = 0$) | Выбрасывание типизированного исключения | `DspError(DspErrorCode.EMPTY_BUFFER)` |
| Одиночный отсчет ($N = 1$) | Корректный возврат тривиальных статистик | $V_{pp} = 0, \text{RMS} = |x[0]|, \mu = x[0]$ |
| Постоянный сигнал (DC) | Оценка частоты невозможна | `valid: false, frequency: 0, cycleCount: 0` |
| Касание нуля без пересечения | Отсутствие смены знака (bounce) | Пересечение **не создается** (0 false crossings) |
| Сигнал $< 1$ полного периода | Недостаточно информации для периода | `valid: false, frequency: 0, cycleCount: 0` |
| Некорректный $f_s \le 0$ | Недопустимый параметр частоты дискретизации | `DspError(DspErrorCode.INVALID_SAMPLE_RATE)` |
| Частота среза $f_c \ge f_s / 2$ | Нарушение теоремы Найквиста-Котельникова | `DspError(DspErrorCode.INVALID_PARAMETER)` |
| Неустойчивые полюса IIR | Полюса $|p| \ge 1$ (нарушение критерия Джури) | `DspError(DspErrorCode.UNSTABLE_FILTER)` |
| Сброс фильтра (`reset()`) | Очистка внутренних линий задержки в 0 | Готовность к независимому потоку |
